# 02: 투표하기

**What to build:** 투표자가 로그인 없이 투표 페이지에서 선택지 하나를 골라 표를 던진다. 투표자당 투표 하나에 한 표이며, 표를 던진 뒤나 마감된 투표에서는 투표 폼이 보이지 않는다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 투표자는 선택지를 고르지 않으면 표를 던질 수 없다
- [ ] 표를 던지면 투표 폼이 사라지고, 새로고침해도 다시 나오지 않는다
- [ ] 같은 투표자는 한 투표에 한 표만 던진다 (다른 투표에는 따로 던질 수 있다)
- [ ] 마감된 투표에는 투표 폼이 보이지 않는다
