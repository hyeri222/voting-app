# 01: DB 스키마 + 투표 만들기

**What to build:** 운영자가 로그인해 질문과 선택지 2~10개로 투표를 만들면, 새 투표 페이지로 이동해 선택지가 입력한 순서대로 보인다. 빈 질문과 중복 선택지는 오류로 막고, 오류가 나도 입력한 값은 지워지지 않는다. DB 스키마(운영자, 세션, 투표, 선택지, 표)는 한 명령으로 반복 적용할 수 있다. 이 티켓에서 브라우저 E2E 테스트 기반(Playwright, 테스트용 Neon DB)도 함께 마련한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 로그아웃 상태에서 운영 화면에 들어가면 로그인 페이지로 이동한다
- [ ] 잘못된 아이디/비밀번호로는 로그인되지 않고 오류가 보인다
- [ ] 운영자가 투표를 만들면 새 투표 페이지로 이동하고 선택지가 입력 순서대로 보인다
- [ ] 공백뿐인 질문, 중복 선택지는 오류로 막힌다
- [ ] 오류가 나도 입력한 질문과 선택지가 남아 있다
- [ ] 선택지 칸은 2개 아래로 줄지 않고 10개 위로 늘지 않는다
- [ ] E2E 테스트는 운영 DB가 아닌 테스트 DB에만 붙는다
