# 03: 결과 보기

**What to build:** 표를 던진 투표자는 선택지별 표 수, 퍼센트, 총 표 수와 자기 선택을 본다. 표를 던지기 전에는 결과가 보이지 않는다. 운영자는 표를 던지지 않아도 결과를 본다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 표를 던지기 전에는 결과가 보이지 않는다
- [ ] 표를 던지면 선택지별 표 수·퍼센트·총 표 수가 보이고 내 선택이 표시된다
- [ ] 투표자 여러 명의 표가 정확히 집계된다
- [ ] 운영자는 표를 던지지 않아도 결과를 본다
- [ ] 마감된 투표에서 표를 던지지 않은 투표자는 결과 없이 마감 안내만 본다
