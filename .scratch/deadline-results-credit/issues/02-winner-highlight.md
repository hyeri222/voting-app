# 02: 결과에서 1위 강조

**What to build:** 결과 막대에서 표가 가장 많은 선택지에 강조 스타일과 "1위" 표시가 붙는다. 공동 1위는 모두 표시하고, 표가 0개면 아무것도 표시하지 않는다. 선택지 순서는 운영자가 입력한 그대로다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 1위가 하나면 "1위" 표시가 정확히 하나 붙는다
- [ ] 공동 1위면 동점인 선택지마다 "1위" 표시가 붙는다
- [ ] 표가 0개인 투표에는 "1위" 표시가 없다
- [ ] 선택지 순서는 입력 순서 그대로다
