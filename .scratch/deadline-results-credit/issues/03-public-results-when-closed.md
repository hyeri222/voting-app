# 03: 마감된 투표의 결과 공개

**What to build:** 마감된 투표는 표를 던지지 않은 투표자도 결과를 본다. 열린 투표는 지금처럼 표를 던진 투표자와 운영자만 결과를 본다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 표를 던지지 않은 투표자가 마감된 투표를 열면 마감 안내와 결과가 보인다
- [ ] 열린 투표에서는 표를 던지기 전까지 결과가 보이지 않는다
- [ ] 이 결정과 반대되던 기존 E2E 테스트를 새 규칙에 맞게 고친다
