# 04: 마감 시각 정하고 보여 주기

**What to build:** 운영자는 투표를 만들 때 마감 시각을 반드시 정한다(기본값 24시간 뒤, 한국 시간). 5분 뒤~30일 뒤 범위를 벗어나면 오류가 나고 입력값은 남는다. 투표 페이지, 홈 목록, 운영 화면에 마감 시각과 남은 시간(페이지를 열 때 기준)이 보인다. 기존 투표도 마감 시각을 갖는다(열린 투표는 7일 뒤, 마감된 투표는 마감한 시각). 최소 간격은 환경변수로 줄일 수 있어 E2E 서버에서 짧게 쓴다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 투표 만들기 폼에 마감 시각 칸이 있고 기본값이 24시간 뒤다
- [ ] 30일보다 먼 마감 시각은 오류로 막히고 입력한 값이 남는다
- [ ] 최소 간격보다 가까운 마감 시각은 오류로 막힌다
- [ ] 새 투표의 페이지와 홈 목록, 운영 화면에 마감 시각(KST)과 남은 시간이 보인다
- [ ] 스키마 명령을 여러 번 실행해도 안전하고, 기존 투표에 마감 시각이 채워진다
